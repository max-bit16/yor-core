Crée un site vitrine multipage haut de gamme pour Renaud Voss
Avocats, cabinet spécialisé en droit des affaires à Paris 8e.
Cible : dirigeants de PME, DG et fondateurs de scale-ups.

CONTRAINTE ABSOLUE : aucune image IA, aucun placeholder
d'image, aucun stock photo. Le design repose entièrement sur
la typographie, les blocs de couleur et les icônes SVG.
L'esthétique doit évoquer une revue juridique de prestige —
pas un site corporate générique.


━━ STACK TECHNIQUE ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- React + Tailwind CSS
- Icônes : bibliothèque Lucide-React exclusivement
- Polices Google Fonts :
    · Titre      → "Playfair Display" (serif, élégant)
    · Corps      → "DM Sans" (sans-serif, lisible)
- Aucune image (ni <img>, ni background-image URL externe)
- Aucune animation lourde — transitions CSS légères uniquement
- Routing multipage : React Router avec 5 routes distinctes


━━ STRUCTURE HTML SÉMANTIQUE ━━━━━━━━━━━━━━━━━━━━━━━━━━━━

"Avocats en droit des affaires à Paris — Renaud Voss Avocats"

━━ DESIGN SYSTEM ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Palette claire et éditoriale (différente d'un site sombre) :
  · Fond principal   → #FAFAF7  (blanc ivoire chaud)
  · Fond secondaire  → #F0EDE6  (crème soutenu)
  · Texte principal  → #1A1A1A
  · Accent           → #2C4A3E  (vert sauge profond)
  · Accent or        → #8B7355  (or brun, numéros et labels)
  · Séparateurs      → #E0DBD3  (beige très clair)

Typographie :
  · H1         → Playfair Display, 96px, italic, #1A1A1A
  · H2         → Playfair Display, 56px, italic, #1A1A1A
  · Labels     → DM Sans, 11px, uppercase, tracking 0.2em, #8B7355
  · Corps      → DM Sans, 16px, line-height 1.8, #1A1A1A
  · Chiffres   → Playfair Display, 80–100px, #2C4A3E

Éléments signature (présents sur toutes les pages) :
  · Ligne verticale fine 1px #2C4A3E, positionnée à 48px
    du bord gauche, court sur toute la hauteur de la page
  · Numérotation éditoriale avant chaque section :
    "01 — EXPERTISES", "02 — CABINET", etc.
    DM Sans 11px uppercase #8B7355
  · Séparateurs horizontaux en tirets fins #E0DBD3
    entre chaque section (jamais de blocs pleins lourds)
