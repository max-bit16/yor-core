Build a dark monochrome landing page for Yamen Global —
a consulting firm. Use React + Vite + TypeScript +
Tailwind CSS + shadcn/ui + Framer Motion.
Fonts: Inter (sans) and Instrument Serif (serif, used for
italic accent words).
The entire theme is pure black (#000) background with
white foreground — the only accent color is a deep violet
used sparingly. Install framer-motion and hls.js.

━━ NOTES CLAUDE CODE (post-Lovable) ━━━━━━━━━━━━━━━━━━━

Les vidéos sont servies directement depuis le CDN Pexels.
Claude Code n'a pas besoin de les télécharger.

Pour chaque composant vidéo, s'assurer que la balise
<video> contient :
autoPlay muted loop playsInline preload="none"

preload="none" est obligatoire pour ne pas pénaliser
le score LCP/PageSpeed — les vidéos ne se chargent
qu'à l'affichage, pas au premier rendu.
