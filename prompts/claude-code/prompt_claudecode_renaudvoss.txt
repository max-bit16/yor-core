━━ ÉTAPE 1 — VERCEL.JSON (routing BrowserRouter) ━━━━━━━━

  Crée un fichier vercel.json à la racine du projet :

  {
    "rewrites": [
      { "source": "/(.*)", "destination": "/index.html" }
    ]
  }

  Ce fichier est indispensable : sans lui, toute navigation
  directe vers une URL (ex: /expertises) renvoie une 404
  sur Vercel avec React BrowserRouter.

  Vérifie qu'il n'existe pas déjà avant de le créer.

━━ ÉTAPE 6 — IMAGES EN .WEBP ━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Analyse tous les fichiers images du projet
  (JPG, PNG, GIF dans /src/assets/ et /public/).

  Pour chaque image trouvée :
  · Convertis en .webp avec qualité 85
  · Mets à jour tous les imports et références dans
    les composants React
  · Ajoute loading="lazy" sur tous les <img> sauf
    ceux du hero (above the fold)
  · Ajoute width et height explicites sur chaque <img>
    pour éviter le Cumulative Layout Shift (CLS)
  · Ajoute un attribut alt descriptif si absent

  Si le projet ne contient aucune image (design 100%
  typographique), indique-le et passe à l'étape suivante.


━━ ÉTAPE 7 — POLICES EN LOCAL ━━━━━━━━━━━━━━━━━━━━━━━━━━

  Vérifie comment les polices sont chargées actuellement.

  Si les polices sont appelées via Google Fonts (lien
  externe ou @import URL) :

  · Télécharge Playfair Display (weights: 400, 700 italic)
    et DM Sans (weights: 300, 400, 500) depuis Google Fonts
  · Place les fichiers .woff2 dans /src/assets/fonts/
  · Crée ou mets à jour /src/styles/fonts.css avec
    les déclarations @font-face locales
  · Supprime tous les appels Google Fonts externes
    (<link> dans index.html ou @import URL dans CSS)
  · Ajoute <link rel="preload"> dans index.html pour
    les deux polices principales (format woff2)

  Format @font-face à utiliser :
  @font-face {
    font-family: 'Playfair Display';
    src: url('/assets/fonts/playfair-display-v37-latin-regular.woff2')
         format('woff2');
    font-weight: 400;
    font-style: normal;
    font-display: swap;
  }
  (répéter pour chaque variante)

  font-display: swap est obligatoire sur chaque déclaration
  pour éviter le Flash Of Invisible Text (FOIT).


━━ ÉTAPE 8 — PERFORMANCES TECHNIQUES ━━━━━━━━━━━━━━━━━━━

  Dans vite.config.ts, vérifie et ajoute si absent :

  · base: '/'
  · build.outDir: 'dist'
  · build.assetsDir: 'assets'
  · build.rollupOptions.output.manualChunks pour séparer
    vendor (react, react-dom) du code applicatif
  · build.minify: 'terser' si terser est disponible,
    sinon 'esbuild'

  Dans index.html, ajoute dans le <head> :
  · <meta name="viewport" content="width=device-width,
    initial-scale=1.0" /> si absent
  · <meta charset="UTF-8" /> en premier si absent
  · <meta name="theme-color" content="#2C4A3E" />
  · <link rel="preconnect" href="https://fonts.googleapis.com" />
    uniquement si les polices ne sont pas encore en local

  Vérifie que le fichier index.html ne contient
  aucun console.log et aucune valeur sensible en dur.


━━ ÉTAPE 9 — ACCESSIBILITÉ & SEO TECHNIQUE ━━━━━━━━━━━━━

  Passe en revue tous les composants et vérifie :

  · Chaque icône Lucide-React a un aria-label descriptif
  · Chaque bouton a un aria-label si le texte seul
    n'est pas suffisamment explicite
  · Chaque <img> a un attribut alt non vide
  · Le formulaire de contact : chaque input a un <label>
    associé via htmlFor / id
  · La hiérarchie des titres est respectée :
    un seul H1 par page, H2 par section, H3 si nécessaire
  · Les liens de navigation utilisent <Link> de React Router
    (pas de <a href> pour les routes internes)
  · La page 404 existe et contient un lien retour accueil

  Ajoute la balise <html lang="fr"> si absente.

  · Un dossier /dist/ avec index.html + assets optimisés
  · Les fichiers sitemap.xml et robots.txt présents
    dans /dist/
  · Le fichier vercel.json présent à la racine

  Affiche le résumé du bundle :
  · Taille totale du JS (objectif < 200kb gzippé)
  · Taille totale du CSS
  · Liste des fichiers générés dans /dist/assets/

  Si des warnings apparaissent, règle-les avant de
  continuer. Ne pousse pas un build avec des warnings.
