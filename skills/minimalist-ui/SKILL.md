# minimalist-ui

When using this skill:
1. Remove unnecessary decoration and competing elements.
2. Strengthen hierarchy through spacing, scale, and typography.
3. Let structure and content do the work.
4. Keep the result calm, efficient, and elegant.

Output expectations:
- Simplify aggressively but intelligently.
- Preserve usability and clarity.
- Favor precision over emptiness.
