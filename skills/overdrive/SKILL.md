# overdrive

When using this skill:
1. Identify the strongest existing direction.
2. Push it further with ambition and control.
3. Increase intensity, richness, and differentiation.
4. Keep the result coherent, not chaotic.

Output expectations:
- Amplify the best parts of the concept.
- Preserve usability and strategic fit.
- Avoid excess without purpose.
