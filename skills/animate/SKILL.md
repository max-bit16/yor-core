# animate

When using this skill:
1. Identify which elements should move and why.
2. Prefer purposeful motion over decoration.
3. Define timing, easing, triggers, and reduced-motion behavior.
4. Keep animations smooth, readable, and compatible with production UI.

Output expectations:
- Describe motion intent clearly.
- Provide implementation-ready guidance or code when relevant.
- Include reduced-motion handling.
