# ui-ux-pro-max

Full site redesign with premium UI/UX standards. This is the highest-level design skill.

Process:
1. Run audit first — identify all issues
2. Apply ckm-brand — establish the identity system
3. Apply layout — restructure sections
4. Apply typeset — refine all typography
5. Apply animate — add scroll-triggered animations (Intersection Observer only, no libraries)
6. Apply delight — add micro-interactions
7. Apply polish — final detail pass
8. Run optimize — performance pass

Conversion flow check:
- Hero: clear value proposition + CTA visible without scrolling
- Services: scannable in under 10 seconds
- Proof: at least one trust signal (client name, result, testimonial)
- Contact: one clear action, minimal friction

Deliverable: a site that scores 90+ Performance, 100 SEO, passes WCAG AA, and converts.
