# design-taste-frontend

When using this skill:
1. Review the frontend through the lens of taste and execution quality.
2. Identify generic, awkward, or visually weak decisions.
3. Upgrade typography, spacing, rhythm, surfaces, and interaction details.
4. Keep recommendations grounded in real implementation.

Output expectations:
- Focus on concrete frontend improvements.
- Prefer fewer, stronger design decisions.
- Aim for a result that feels designed, not templated.
