# distill

When using this skill:
1. Identify the main signal versus secondary detail.
2. Remove repetition, clutter, and weak phrasing.
3. Preserve the essential structure and intent.
4. Deliver a tighter, clearer version.

Output expectations:
- Lead with the distilled version.
- Keep important nuance when it matters.
- Favor clarity, compression, and usefulness.
