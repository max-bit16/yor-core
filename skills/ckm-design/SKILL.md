# ckm-design

Apply a cohesive design language across all components.

Rules:
- Every component must use only the defined brand tokens (no ad-hoc colors or sizes)
- Visual treatment consistent: same border-radius, same shadow style, same hover pattern throughout
- On-brand details: accent color appears in exactly the same way across all CTAs
- Section rhythm: alternating background treatments (dark/light) follow a predictable pattern
- Icons: one icon library only (Lucide-React), consistent size (20px or 24px, never mixed)
- Images: consistent aspect ratios within each context (cards always 16:9, avatars always 1:1)
