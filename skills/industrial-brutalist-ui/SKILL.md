# industrial-brutalist-ui

When using this skill:
1. Lean into structure, contrast, and raw visual honesty.
2. Use typography, grid, borders, and density as primary tools.
3. Keep the interface forceful but still usable.
4. Avoid accidental messiness; the severity must feel designed.

Output expectations:
- Define the brutalist rules clearly.
- Show how the style appears in layout, type, and components.
- Preserve clarity and interaction quality.
