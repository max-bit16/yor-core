# optimize

When using this skill:
1. Identify friction, waste, bottlenecks, or weak spots.
2. Improve the solution without changing the core objective.
3. Prioritize high-impact optimizations first.
4. Keep the result robust and maintainable.

Output expectations:
- State what is being optimized.
- Make improvements measurable when possible.
- Avoid premature or cosmetic optimization.
