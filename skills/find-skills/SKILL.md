# find-skills

When using this skill:
1. Analyze the user request and its sub-tasks.
2. Map each need to the most relevant available skills.
3. Prefer the smallest useful set of skills.
4. Explain why each suggested skill fits.

Output expectations:
- List the recommended skills clearly.
- Include short rationale for each match.
- Avoid redundant or weakly related suggestions.
