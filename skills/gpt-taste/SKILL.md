# gpt-taste

When using this skill:
1. Evaluate the output for taste, restraint, and originality.
2. Remove generic or overdone choices.
3. Strengthen cohesion, confidence, and polish.
4. Prefer fewer, better decisions over added complexity.

Output expectations:
- Focus on qualitative improvement.
- Explain what feels off and how to elevate it.
- Aim for refined, contemporary output.
