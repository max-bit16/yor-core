# colorize

When using this skill:
1. Assess the current palette and usage.
2. Define the role of each color: primary, support, surface, accent, status.
3. Improve harmony, contrast, and emphasis.
4. Keep accessibility and visual restraint in mind.

Output expectations:
- Propose a clear palette logic.
- Explain where color should and should not be used.
- Prioritize readability and hierarchy.
