# redesign-existing-projects

When using this skill:
1. Assess what currently exists before changing it.
2. Identify what to preserve, remove, and rework.
3. Improve structure, hierarchy, aesthetics, and usability.
4. Deliver a redesign that feels intentional and realistic.

Output expectations:
- Respect the existing project's context.
- Distinguish incremental fixes from deeper redesign moves.
- Keep recommendations implementation-aware.
