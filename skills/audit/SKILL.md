# audit

When using this skill:
1. Inspect the current artifact carefully.
2. Evaluate strengths, weaknesses, risks, and missing pieces.
3. Prioritize findings by impact and urgency.
4. Recommend concrete fixes, not vague advice.

Output expectations:
- Organize findings by category.
- Separate critical issues from nice-to-have improvements.
- Make recommendations actionable.
