# adapt

When using this skill:
1. Identify the current state and the target context.
2. Preserve what already works.
3. Modify tone, structure, density, and output format to fit the target.
4. Keep the result practical and directly reusable.

Output expectations:
- Show the adapted version first.
- Keep changes intentional, not cosmetic only.
- Explain tradeoffs briefly when they matter.
