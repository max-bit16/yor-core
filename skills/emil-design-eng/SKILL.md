# emil-design-eng

When using this skill:
1. Translate design intent into engineering-friendly decisions.
2. Balance aesthetics, feasibility, maintainability, and UX quality.
3. Resolve ambiguity between mockup and implementation.
4. Produce output that a product-minded engineer can apply directly.

Output expectations:
- Connect design rationale to technical execution.
- Prefer robust patterns over hacks.
- Keep recommendations specific and buildable.
