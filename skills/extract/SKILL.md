# extract

When using this skill:
1. Identify what needs to be extracted.
2. Scan the source methodically.
3. Pull out relevant items in a structured format.
4. Avoid mixing extraction with unnecessary interpretation.

Output expectations:
- Return clean, structured extracted data.
- Preserve source meaning accurately.
- Separate raw findings from optional interpretation.
