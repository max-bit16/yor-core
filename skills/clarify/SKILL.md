# clarify

When using this skill:
1. Identify ambiguity, confusion, or overload.
2. Simplify wording, structure, and sequencing.
3. Make the core intent obvious.
4. Keep the result precise without becoming verbose.

Output expectations:
- Produce the clarified version first.
- Improve readability and decision-making.
- Remove unnecessary ambiguity.
