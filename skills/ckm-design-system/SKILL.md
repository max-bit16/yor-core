# ckm-design-system

Generate a design system for the project.

Deliverable:
1. Color tokens (CSS variables + Tailwind extend config)
2. Spacing scale (4px base, tokens: xs=4 sm=8 md=16 lg=24 xl=32 2xl=48 3xl=64 4xl=96 5xl=128)
3. Typography scale (font-size, line-height, font-weight per level: display/h1/h2/h3/body/small/caption)
4. Component inventory: list all reusable components with their variants
5. Usage rules: when to use each variant

Output as a DESIGN_SYSTEM.md file at the project root.
Do not implement changes — document only, unless explicitly asked.
