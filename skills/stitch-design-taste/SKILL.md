# stitch-design-taste

When using this skill:
1. Identify inconsistencies across the parts.
2. Define the unifying visual logic.
3. Harmonize typography, spacing, color, and component behavior.
4. Make the whole feel authored by one clear design mind.

Output expectations:
- Describe the shared design rules.
- Resolve mismatches instead of averaging them out.
- Aim for coherence with personality.
