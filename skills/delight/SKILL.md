# delight

When using this skill:
1. Identify moments where subtle delight improves the experience.
2. Focus on feedback, transitions, empty states, and completion moments.
3. Add warmth without distracting from core tasks.
4. Keep the result polished and product-appropriate.

Output expectations:
- Suggest concrete delightful moments.
- Keep them lightweight and intentional.
- Avoid gimmicks that reduce usability.
