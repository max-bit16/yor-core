# ckm-brand

Define the brand identity system for the current project.

Deliverable (output as markdown):
- Logo usage rules (size, clear space, forbidden uses)
- Color tokens: primary, secondary, accent, background, text, muted (hex + Tailwind name)
- Typography scale: font families, size scale (xs → 4xl), weight usage per level
- Tone of voice: 3 adjectives, 3 sentence examples, 3 things to never say
- Brand consistency checklist (10 items to verify before delivery)

Apply these tokens as CSS variables in the project after definition.
