# ckm-banner-design

Create a hero banner with strong visual impact.

Rules:
- Typographic composition: H1 fills dominant portion of the viewport (min 60px)
- Layered depth: background color/gradient → optional geometric element → text → CTA
- Brand colors only: no gradients that introduce off-brand hues
- One primary CTA button, maximum one secondary link
- Subtitle: max 2 lines, weight 300–400, never competing with H1
- Mobile: H1 min 40px, CTA full-width
- Animation: H1 fades up on load (0.4s), CTA appears 200ms later
- No stock photography in the hero unless the client has provided brand-quality assets
